# Financial Mathematics Toolkit

A Python package for analysing investment returns and price-based risk.

## Purpose

This project demonstrates basic financial mathematics calculations
using sample closing prices.

## Features

- Calculate simple returns.
- Calculate annualised volatility.
- Calculate maximum drawdown.
- Plot closing prices.

## Project structure

- `finmath/`: calculation functions.
- `demo/`: demonstration scripts.
- `data/`: sample price data.
- `pyproject.toml`: package configuration.

## Requirements

Python 3.8 or later, NumPy and Matplotlib.
